# Endfield Touch Patch

## 用途

为《明日方舟：终末地》Windows PC 版启用移动端触屏界面，保留普通账号登录，方便通过 Moonlight 使用触屏操作。

补丁同时修复好友页标签、关闭按钮等 UI 在触摸后只按下、不弹起的问题。工具支持交互式应用、消除补丁和版本识别，无需下载修改后的游戏 DLL。

## 使用

1. [下载脚本](https://github.com/orangetooth/endfield-touch-patch/archive/refs/heads/main.zip)，解压到任意目录。
2. 完全退出游戏，双击 `run.cmd`。
3. 输入包含 `Endfield.exe` 和 `GameAssembly.dll` 的游戏根目录，例如 `D:\Hypergryph Launcher\games\Endfield Game`。
4. 按菜单选择操作：

|选项|功能|
|---|---|
|1|识别版本并应用对应补丁|
|2|消除补丁，恢复原版文件|
|3|查看版本及补丁状态|
|4|更换游戏目录|
|5|更新支持版本规则库|
|0|退出工具|

请保持 `run.cmd`、`patch.ps1`、`rules.ps1`、`profiles.json` 位于同一目录。需要 Windows PowerShell 5.1 或 PowerShell 7，无需安装 Python。若提示没有文件写入权限，请用管理员终端运行脚本。

**补丁应用后持续生效，退出游戏不会自动消除。** 需要还原时，再次运行并选择2。应用时会在游戏目录保存带版本哈希的原版备份，不同版本分别保存。

默认仅在遇到未识别版本时联网检查本仓库的最新规则；也可选择5主动更新。需要离线使用时运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\patch.ps1 -Offline
```

## 支持版本

|游戏版本|平台|补丁|
|---|---|---|
|1.5.3|Windows PC|v3|

**v3 是本项目补丁编号，不是游戏版本号。** 工具会进一步校验游戏文件，版本名称相同也必须匹配已收录的文件哈希才能应用。

已安装本项目 v1/v2 的同一客户端可直接升级至 v3，或恢复原版。诊断版文件需先使用原诊断工具恢复。

游戏更新后，需要新的适配规则。工具会按文件哈希选择已收录版本的补丁；若更新规则后仍未匹配，将保留游戏文件并提示暂不支持，不会强行套用旧补丁。完整版本规则见 [profiles.json](profiles.json)。

## 原理

工具识别 `GameAssembly.dll` 的完整 SHA-256，从版本规则库选择对应的修改位置及目标哈希，然后在本地生成补丁文件。

当前补丁启用游戏已有的本地触屏输入，并取消 UI 输入模块中会清掉待处理按钮状态的统一指针复用分支，让触摸抬起事件能够正常交给按钮处理。不补发点击，不修改普通登录流程，也不关闭、修改或绕过 ACE。

v3 共修改四处汇编，意图如下（偏移均为当前支持版本的 DLL 文件偏移）：

|文件偏移|汇编改动|意图|
|---|---|---|
|`0x476391F`|`call …` → `mov eax, 1`|将本地输入初始化所选的输入类型固定为 Touch，启用触屏操作界面。|
|`0x32E4FE3`|`call …` → `mov eax, 1`|让本地输入提供器接受 Touch 类型，不再受原移动平台判断限制。|
|`0x32E52EA`|`jmp …` → `mov al, 1; ret; nop; nop`|在原有栈清理后直接返回“支持触屏”，保持本地触屏能力判断一致。|
|`0x2E26F79`|`je …` → 六个 `nop`|取消通往统一指针复用路径的条件跳转，让该路径改用独立指针，避免后续鼠标位置事件清掉尚未处理的触摸抬起状态。|

前三处负责启用触屏，第四处负责修复 UI 按钮卡在按下状态。`nop` 是空操作，用于保持指令占用长度不变。

应用及还原均校验修改位置和完整文件哈希，验证后再替换游戏文件。已识别的旧补丁会先还原为对应原版，再生成目标补丁。消除补丁通过反向修改及原版哈希验证完成，不依赖备份仍然存在。
